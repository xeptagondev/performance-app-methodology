# Procurement

## Introduction


## Organisational Objective

The procurement process should take no longer than 48 calendar days. 



## Data

To get data columns export for this indicator.

## Calculation of Scoring 

For every 1% over 48 days, 1 point is deducted from the total score. 

So the cutoff points for green is 55 days (15% above 48 days), and for red is 62 days (30% above 48 days). 

 

## Traffic Light System

| Traffic Light | Score |
| ------------- | ----- |
| Green         | 85+   |
| Yellow        | 70+   |
| Red           | <70   |
